Как пользоваться

Диаграмма — это дерево папок проекта. Стрелка значит «импортирует». Чем ниже блок, тем он внутреннее.

Провалиться внутрь

Двойной клик по папке открывает её содержимое. Папка подписана курсивом, внутри список ▸ подпапка и файлы.

Двойной клик по файлу открывает карточку: экспорт, кто от него зависит и исходник. Ссылка «Открыть в Cursor» ведёт на эту строку.

Двойной клик по овалу (блок другого уровня, который торчит сбоку) переносит к нему.

На x5-vyruchaem путь такой: корень → frontend → entities → article → файл.

Подняться обратно

Жест Куда
Esc или кнопка ← На уровень выше. Если открыта карточка файла — сначала закрывает её.
Крошки сверху x5 / frontend / entities Клик по любому звену прыгает сразу туда.

Смотреть, не проваливаясь

Жест Что делает
Один клик Выделяет блок. Справа — его связи и нарушения. Остальные стрелки тускнеют.
Клик по пустому месту Снимает выделение. Справа сводка всего уровня.
Навести на стрелку Список импортов, которые она объединяет. ✕ — нарушение.
Имя в правой панели Прыгает к этому модулю.
Колесо Прокрутка холста. Это обычный скролл, не зум.
Ctrl + колесо, Ctrl + / −, кнопки − 100% + Масштаб. Ctrl 0 возвращает 100%.
R Перечитать диаграмму. Само обновление и так идёт при сохранении файлов.

Что означают блоки

Цифра в левом верхнем углу — уровень. 0 внизу, это внутренний слой (shared, Enums). Наружу уровень растёт, routes и pages наверху. Хорошая стрелка смотрит вниз: внешний слой зависит от внутреннего.

Вид Значение
Курсив Папка. Двойной клик открывает её.
▸ и обычная строка Подпапка и файл внутри блока.
◆ Astro-компонент.
API Файл, который только реэкспортирует (index.ts).
I Только типы, интерфейс или enum.
Зелёная заливка Нарушений нет.
Красная заливка и ✕12 Столько импортов нарушают правило. ✕ в углу блока.
Овал Модуль не с этого уровня. Двойной клик переносит к нему. Кнопка npm добавляет овалы пакетов.

Стрелки

Линия Значение
Сплошная серая Импорт в правильную сторону.
Красная Нарушение. Внутренний слой импортирует внешний, или слайс импортирует соседний слайс (entities/article → entities/page).
Пунктир Только import type.
Точки HTTP: фронт вызывает /v1/…, стрелка идёт в контроллер бэкенда. Наведение показывает маршрут.

Кнопка Стрелки прячет линии. Кнопка Компактно оставляет только имена блоков, без списка файлов. Кнопка Цвет переключает заливку: нарушения или метрика D (насколько блок далёк от «стабильного и абстрактного»).

Правая панель

У выделенного блока:

Число Смысл
Ca Сколько чужих модулей его импортируют. 0 — никто не пользуется, кандидат на удаление.
Ce Сколько модулей импортирует он сам.
I Нестабильность, Ce / (Ca + Ce). Близко к 1 — блок легко менять, от него никто не зависит.
A Доля абстрактного: интерфейсы и абстрактные классы среди файлов блока.
D Расстояние до главной последовательности. 0 — либо стабильный и абстрактный, либо нестабильный и конкретный.

Ниже списки «Зависит от» и «Используется в». Клик по строке открывает тот модуль.

Карточка файла

Двойной клик по файлу. Слева экспорт и связи, справа исходник. Клик по строке экспорта прокручивает исходник к ней и меняет ссылку «Открыть в Cursor». Esc или × закрывает карточку и не уходит с уровня. Рядом с именем файла — бейдж расширения (TS / Astro / SCSS…), как в дереве Source Control. Любые файлы в сканируемых каталогах (scss, yml, md, svg…) видны в папках и открываются; в стрелки зависимостей входят только модули с import/export. Бинарники — в дереве, в карточке пометка ⟨ binary file ⟩.

Diff для MR

Сервер запускается с веткой, с которой сравнивать: pnpm uml --diff origin/dev. В шапке плашка DIFF.

Цвет Значение
Зелёная обводка — блок целиком новый (все файлы внутри добавлены) или новая стрелка. Папка, которая уже была, с новыми файлами внутри — не зелёная.
Жёлтая обводка — внутри есть изменения или новые файлы, но сам блок не появился с нуля.
Серая приглушённая блок без изменений (соседи по стрелкам и остальной фон).
Красный пунктир обводка — удалено. Заливка остаётся приглушённой.
Красная в этом режиме только новое нарушение, которого не было на базе.

Кнопка Только изменения прячет всё, чего diff не коснулся, и оставляет соседей по стрелкам. Строка diff +1 ~13 −0 справа: добавлено, изменено, удалено.

Двойной клик по изменённому, новому или удалённому файлу открывает карточку сразу на diff кода относительно базы (зелёные строки добавлены, красные удалены). Слева номер строки файла. «Открыть в Cursor» открывает первую изменённую строку, клик по строке выбирает другую. Новый файл, которого git ещё не видит (??), показывается целиком как добавление. Кнопка Файл в шапке карточки показывает исходник целиком. У папки diff кода нет — внутри неё несколько файлов, провалитесь до файла.

Заметка агенту

Поле «Агенту» внизу панели. Напиши, что не так, и нажми «Отправить». Вместе с текстом уходит, какая диаграмма открыта, какой уровень и что выделено. Потом скажи агенту разобрать inbox.

Запуск

Команда Зачем
pnpm uml Диаграмма на 127.0.0.1:4815. Перечитывает файлы сама.
pnpm uml --open То же и сразу открывает браузер.
pnpm uml --diff origin/dev Подсветка изменений относительно ветки.

Команды из каталога frontend/. Страница гайда — /guide, кнопка ? в шапке диаграммы.
