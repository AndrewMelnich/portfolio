Управление

Клик — выделить. Двойной клик — провалиться / карточка модуля. ⌘/Ctrl+клик по компоненту — его .astro; по типу — к определению (в т.ч. import type / node_modules). У изменённого файла карточка открывается на diff кода, кнопка «Файл» — исходник целиком. Esc — вверх. Наведи на стрелку — список импортов. Ctrl+колесо / Ctrl± — зум. R — перечитать.
Красная заливка — нарушение слоя или кросс-импорт слайсов. Пунктир — только import type. Точки — вызов HTTP. Diff: зелёное новое, жёлтое изменённое, красный пунктир — удалено. Приглушённо-серое без изменений — только при включённом «Только изменения».
