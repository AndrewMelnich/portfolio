# Collapse

Аккордеон-компонент с плавной анимацией раскрытия/скрытия контента.

## Использование

### Базовое использование

```astro
---
import Collapse from '@/shared/ui/Collapse/Collapse.astro';
---

<Collapse>
    <template slot="trigger">
        <h3>Заголовок секции</h3>
    </template>
    <p>Содержимое секции, которое будет скрыто/показано при клике на заголовок</p>
</Collapse>
```

### Атрибуты

- Все стандартные HTML-атрибуты элемента `<div>`
- `class` - дополнительные CSS-классы

### События

Компонент автоматически генерирует:

- **expanded** - при раскрытии секции
- **collapsed** - при сворачивании секции

### Слоты

- **trigger** - содержимое кнопки-триггера (обязательный)
- **default** - содержимое секции (обязательный)

### CSS-переменные

- `--transition-length` - длительность анимации (по умолчанию: 0.3s)
- `--transition-timing` - функция анимации (по умолчанию: ease)
