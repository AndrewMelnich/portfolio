# Tooltip

Всплывающая подсказка с автоматическим позиционированием и плавными анимациями.

## Использование

### Базовое использование

```astro
---
import Tooltip from '@/shared/ui/Tooltip';
---

<Tooltip>
    <button>Наведите на меня</button>
    <div slot="tooltip">Это всплывающая подсказка</div>
</Tooltip>
```

### Слоты

- **default** - основной контент (обязательный)
- **tooltip** - содержимое подсказки (обязательный)

### События

Компонент автоматически обрабатывает:

- **Показ**: hover, focus, click на основном элементе
- **Скрытие**: mouseleave, blur с задержкой
- **Автоматическое позиционирование**: предотвращение выхода за границы экрана

### CSS-переменные

- `--bg-color` - цвет фона подсказки (по умолчанию: #4e4e4e)
- `--border-color` - цвет границы (по умолчанию: #484848)
- `--shift-x` - автоматически устанавливаемое смещение для стрелки
