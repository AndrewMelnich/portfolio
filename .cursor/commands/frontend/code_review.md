# Frontend code review

Проведи комплексный code review frontend-кода. Проанализируй код по следующим критериям:

## Функциональность

- Код делает то, что должен
- Обработаны крайние случаи
- Обработка ошибок адекватна
- Нет очевидных багов или логических ошибок

## Архитектура и структура

- Соответствие Feature Sliced Design (FSD)
- Правильность разделения на слои (shared, entities, features, widgets, views ('pages' в оригинальном FSD. В Astro 'pages' отвечает за роутинг.), app)
- Корректность импортов между слоями
- Логичность группировки компонентов и утилит

## Качество кода

- Соблюдение принципов SOLID и DRY
- Отсутствие дублирование кода (идентичный или максимально похожий)
- Сложность функций и компонентов
- Читаемость и поддерживаемость

## TypeScript

- Типизация (избегание `any`, корректность типов)
- Использование generic-типов где необходимо
- Правильность интерфейсов и типов

## React

- Правильное использование хуков
- Оптимизация рендеринга (memo, useMemo, useCallback)
- Корректность lifecycle методов
- Избегание anti-patterns

## Стили (SCSS)

- Соблюдение БЭМ методологии
- Разумное разбиение на файлы

## Безопасность

- Нет явных уязвимостей безопасности
- XSS уязвимости
- Небезопасная работа с пользовательскими данными
- Проблемы с валидацией
- Нет захардкоженных секретов

## Производительность

- Неоптимальные запросы к API
- Избыточные ре-рендеры
- Неэффективная работа с большими списками
- Проблемы с загрузкой ресурсов

## Accessibility

- Семантическая разметка
- Корректность aria-атрибутов
- Поддержка клавиатурной навигации
- Контрастность и читаемость

## Потенциальные баги

- Race conditions
- Memory leaks
- Некорректная обработка ошибок
- Проблемы с асинхронным кодом
