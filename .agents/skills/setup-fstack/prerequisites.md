# Prerequisites

Catalog for `/setup-fstack`. Probe every row after **App** is known. Do not write this list into `project.md` or `config.json`.

`{pm}` is the package manager the app lockfile shows (`pnpm`, `npm`, or `yarn`). Run npm installs in `<app>` (the directory that owns the frontend `package.json`).

## Levels

| Level           | On missing           | Setup behavior                                                                                                                                                                                                                    |
| --------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **required**    | Hard block for Prove | One question listing all missing required items. On yes: run each row's `install` (npm into `<app>` `devDependencies` + post-install, or `npx skills add` for skill rows). On no: outcome **partial: prerequisites**; skip Prove. |
| **recommended** | Soft                 | Do not install. Checks scripts skip missing bins. Report status + install command.                                                                                                                                                |
| **external**    | Soft                 | Do not install or edit MCP/skills config. Report status + install command.                                                                                                                                                        |

Missing **recommended** or **external** never makes setup fail. Missing **required** after a declined install does.

## Probe notes

- Prefer resolving packages from `<app>` the same way `verify-ui` / `qa-review` do (`require` / `createRequire` on the app `package.json`).
- Batch all missing **required** into one ask. Install only what the user accepts.
- Do not add ESLint/Stylelint/Prettier “for completeness” when they are absent.
- Do not edit MCP config. Install foreign skills only when a **required** catalog row says so (`mattpocock-skills`, `pstack-principles`).
- Consuming projects refresh skills listed in their `skills-lock.json` with `npx skills update -y`.
